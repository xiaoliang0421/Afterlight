## 续作约束与交接

1. **预算**：fal 文生视频与语音检查累计授权 **US$10**，最近记录 **US$4.22 已确认或保留费用**，最多余 **US$5.78**；再次调用前复核持久台账，不重置历史，不让脚本与线上测试各算一份额度。超出剩余范围的验收先列缺口。DeepSeek 有独立授权，其保守记账不能冒充实际账单，也不能错误计入 fal 已确认支出。
2. **保留既有策略**：英文界面及成片、用户原始提示词留存；各故事独立，按队列逐次接续；免费文生与付费参考分开。图生/参考视频的真实测试继续暂停。
3. **凭据**：使用 macOS 钥匙串和 Cloudflare Secrets；恢复工作时检查凭据和表单有效性。工程文档只记名称/状态，不记密钥。
4. **域名**：继续用 `app.tailrelay.com`。若以后迁域名，同步 OAuth 回调、PUBLIC_ORIGIN、Turnstile、支付链接/回调和分享地址；保留数据库及故事身份，重新验证登录。
5. **验证证据**：本地 fixture、Mock、独立模型实验、远程 API 和真实浏览器验收分别记清。修复前的失败记录保留；没有证据的 release 项不能勾选。
6. **提交**：每一批实现或文档完成后做适当检查，提交并推送 GitHub，记录提交号；只提交本产品相关文件。

建议续作顺序：**A01 → A02 → A03/A04 → B01/B02 → B03/B04/B06 → B08**；B05/B07 可并行准备，C01/C02 在沙盒独立推进，C03 的真实付费测试等待后续授权。既有部署与代码推送授权继续有效；上表列出的未回复条款、凭据和商业选择不能因等待时间变长而视为已确认。
